# CO-TO — Economical Token

CO-TO is a local Flask utility that converts document files into clean Markdown for AI-ready context.

Live Demo:
https://nracare.pythonanywhere.com

## Features

- Convert TXT, MD, DOCX, PDF, PPTX, XLSX, CSV, HTML, and source code files
- Multi-file session support
- Download Selected and Download All
- Ultra-Pure mode for lighter text output
- Dark/light theme
- ID/EN language switch
- Local-first workflow
