FAQ

Pertanyaan yang sering muncul

Jawaban singkat tentang Markdown, token, privasi, dan mode pemrosesan.

Kenapa CO-TO memakai Markdown?

Markdown menjaga struktur tetap jelas tanpa membawa markup berat yang tidak perlu.

Apakah Markdown selalu lebih hemat token?

Biasanya iya untuk dokumen berformat berat, terutama dibanding HTML mentah atau metadata berulang.

Apakah estimasi token di CO-TO akurat?

Estimasi bersifat pendekatan cepat, cukup untuk membandingkan versi standar dan Ultra-Pure.

Apakah file saya dikirim ke internet?

Saat dijalankan lokal, konversi berlangsung di perangkat sendiri melalui Flask lokal.

Kapan Ultra-Pure Mode dipakai?

Pakai saat targetnya prompt paling ringkas. Matikan jika simbol Markdown standar masih dibutuhkan.

Format file apa saja yang didukung?

CO-TO mendukung TXT, MD, CSV, XLSX, DOCX, PDF, PPTX, HTML, dan beberapa source code.

Apa bedanya Download Selected dan Download All?

Download Selected mengunduh file aktif saja. Download All menggabungkan semua hasil sukses dalam satu file Markdown.

Apakah tabel dari Word/PPTX tetap terbaca?

Tabel native dibangun ulang sebagai tabel Markdown agar struktur kolom tetap terlihat.

Kenapa hasil dari gambar belum bisa dibaca?

Gambar membutuhkan OCR. Fitur itu sengaja dipisahkan agar converter teks tetap ringan dan stabil.
